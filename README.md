# Project Nexus 局域网项目进度综合管理系统

新增个人任务自动续订、无字数任务周区块进度记录、区块附件上传，以及更便捷的日期选择体验。

## 本版新增功能

### 1. 在线文档防误删与回收站

- 学生删除自己上传的文档时，会先弹出确认提示。
- 删除不会立刻清除文件，而是移动到“文档回收站”。
- 回收站中可以恢复文档。
- 回收站中也提供“永久删除”，执行前会再次确认。
- 文档恢复后，若文档绑定了任务，系统会重新将文档正文同步到任务正文。

入口：

```text
/documents/trash
```

### 2. 本月签到日历

- 控制台中“本月已签到 X 天”现在默认折叠。
- 点击后以日历形式查看本月已签到、未签到、未到日期。
- 教师与管理员在“学生任务观察”页面中，也可以展开查看每个学生的具体签到日历。

入口：

```text
/
/students/tasks
```

### 3. 紧急登录只读模式

- 登录页新增“忘记密码？使用紧急登录只读模式”。
- 学生或教师忘记密码时，可以只凭用户名或学号进入账户。
- 紧急登录依然会自动签到。
- 紧急登录状态下，系统只能查看内容，不能创建任务、上传文档、编辑文档、删除文件、切换任务状态等。
- 紧急登录后会弹出提示：

```text
忘记密码的场合，请联系管理员！
```

### 4. 个人任务开始日期

- 学生创建个人任务时，系统自动填入当天作为“开始日期”。
- 开始日期只读，不需要手动填写。
- 截止日期不能早于开始日期。
- 修改个人任务时也会继续检查截止日期是否合法。

### 5. 个人任务逾期确认弹窗

- 学生正常登录后，如果存在已过截止日期且未完成的一次性/周常个人任务，系统会自动弹窗询问是否已经完成。
- 点击“是，已完成”后，该个人任务会自动变为“已完成”。
- 点击“稍后处理”只关闭本次提醒，不改变任务状态。

### 6. 个人任务自动续订

- 学生创建个人任务时，如果周期类型选择“日常”，系统会每天自动生成当天任务实例。
- 周期类型选择“周常”时，系统会每周自动生成当周任务实例。
- 自动续订规则会显示在“个人任务”页面。
- 用户可随时取消或恢复自动续订。
- 日常任务不会进入逾期确认弹窗，系统只提醒用户今天要做什么，避免每天都重新创建任务。

### 7. 无字数任务的周区块进度

- 教师分配任务时，目标字数填 0 且设置截止日期，会启用“周区块进度记录”模式。
- 一次性个人任务也会根据开始日期与截止日期生成进度区块。
- 如果任务跨度超过一周，系统按每周一个区块拆分进度条。
- 学生在某个区块记录进展或上传附件后，进度条会推进到对应周。
- 即使某一周没有记录，下一周记录后进度仍会推进到新的周区块。
- 教师和管理员可在教师分配任务详情页浏览学生的周区块记录与附件。

### 8. 日期选择体验优化

- 教师发布任务和学生创建个人任务时，截止日期为必填项。
- 支持浏览器原生日历选择器；在支持 `showPicker()` 的浏览器中，点击日期输入框会直接展开日历窗口。

## 既有主要功能

- 管理员账号管理
  - 管理员可浏览、编辑教师/学生资料
  - 管理员可创建教师账号
  - 管理员可删除教师或学生账号
  - 管理员可提交新管理员创建申请；申请需由两名其他管理员同意后生效
  - 管理员账号不允许通过页面删除

- 学生账号
  - 学生可通过登录页自助创建学生账号
  - 学号格式与唯一性校验沿用上一版规则
  - 学生可创建和维护个人日常/周常/一次性任务

- 在线文档
  - 支持上传 docx / txt / md
  - 可在网页中编辑、保存为历史版本
  - 可绑定到教师分配的任务并同步字数进度

- 任务插图库
  - 任务详情页可上传插图
  - 学生只能给自己负责的任务上传插图
  - 教师/管理员可给所有任务上传插图
  - 插图支持左右箭头切换、缩略图选择、点开原图、复制图片


- 一次性个人任务节点进度
  - 不再一次性开放所有未来区块
  - 平台按开始日期到截止日期计算总周期，每 7 天设置一个进展节点，最后不足 7 天时在截止日设置最终节点
  - 只有节点日期到来后才显示“本周进展”填写窗口
  - 文字记录为必填，附件为选填
  - 保存记录后，进度条按该节点对应的累计天数百分比推进
  - 未来节点只显示预告，不能提前填写

- AI 管家初步功能
  - 可对上传文档生成简单总结
  - 未配置外部 AI 接口时，自动使用本地抽取式总结
  - 配置外部 OpenAI-compatible 接口后，可调用外部模型生成总结
  - 如果文档绑定到主任务下的分支任务，系统会基于总结比较同一主任务下其他分支任务的文档相似性

## 运行方式

```bash
cd lan_project_manager
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器访问：

```text
http://127.0.0.1:8000
```

## 管理员创建审批

- 任一管理员可在“账号管理”中提交管理员创建申请。
- 申请人不能同意自己提交的申请。
- 两名其他管理员分别同意后，系统自动创建新管理员账号。
- 管理员登录账号由系统随机生成，并在申请记录中显示。
- 待审批申请可由申请人撤回。
- 旧版 `admin` 账号会在首次启动新版时迁移为 `Kuiruru`，原关联数据保留。


- “我的个人任务”初始只显示“创建个人任务”“自动续订规则”“个人任务清单”三个栏目标题；展开后才能创建、修改或记录进度。
- 控制台、在线文档、模板库、任务详情、账号管理、学生任务观察、AI 管家等页面的主要面板也会默认收起，只保留栏目标题。
- 如果提交表单后出现错误或成功提示，相关面板会自动保持展开，避免用户看不到反馈。
- 该优化只影响页面展示方式，不改变原有权限、数据表、任务逻辑和运行命令。
